Usage notes

Short guidance for humans and AI tools before copying the pattern.

Use Document Native when you need interfaces that borrow restraint from docs and notes. It works best when the interface needs clarity before spectacle.

Do not make the document native flashy, noisy, over-animated, or decorative for its own sake. Avoid random glow, heavy gradients, excessive borders, oversized type, unclear hierarchy, and generic SaaS filler.
