Usage notes

Short guidance for humans and AI tools before copying the pattern.

Use Gradient Mesh when you need organic mesh gradients that blend multiple color points. It works best when the interface needs clarity before spectacle.

Do not make the gradient mesh flashy, noisy, over-animated, or decorative for its own sake. Avoid random glow, heavy gradients, excessive borders, oversized type, unclear hierarchy, and generic SaaS filler.
