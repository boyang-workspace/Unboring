Usage notes

Short guidance for humans and AI tools before copying the pattern.

Use Smooth Cursor when you need a custom cursor that follows mouse movement with smooth easing. It works best when the interface needs clarity before spectacle.

Do not make the smooth cursor flashy, noisy, over-animated, or decorative for its own sake. Avoid random glow, heavy gradients, excessive borders, oversized type, unclear hierarchy, and generic SaaS filler.
