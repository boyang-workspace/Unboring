Create a Select component for an AI-generated interface using shadcn-style composition. Use shadcn/ui select as the implementation base. The component should support default, muted, error, disabled variants and default, hover, focus-visible, disabled, error, filled states. Include clear anatomy for Trigger, Value, Content, Item, Indicator. Keep the visual language black, white, and gray with subtle borders, practical spacing, accessible focus states, and no decorative noise.
Negative Prompt
Do not invent a custom component API when shadcn/ui select already covers the base behavior. Avoid random gradients, oversized radii, unclear disabled states, missing labels, icon-only controls without accessible names, and variants that change layout unexpectedly.
