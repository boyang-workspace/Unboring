# UnBoring Project Brief

## Core Idea

UnBoring is a product and open-source library for vibe coders who need better UI design direction. It helps engineers, product managers, indie hackers, and AI agents quickly find visual ideas, design systems, motion patterns, templates, prompts, and CSS that can be applied to real products and websites.

The product should not become only a UI kit. A UI kit is too narrow. The long-term direction is a creative design reference system that helps AI and agents generate interfaces that are more dynamic, expressive, useful, and emotionally appropriate for the project.

## Pain

Current AI-generated UI often feels boring, repetitive, and template-driven. Vibe coders may spend a lot of tokens asking for better design, but the result still tends to look like default Tailwind, shadcn, generic SaaS cards, oversized headings, and predictable gradients.

UnBoring should reduce that waste by giving humans and agents concrete design vocabulary: styles, motion, interaction models, page structures, negative prompts, and reusable implementation tokens.

## Audience

- Vibe coders who can build quickly but want better visual taste.
- Engineers and product managers who need UI direction without becoming designers.
- Designers who want to contribute reusable design methods, styles, motion ideas, and templates.
- AI agents that need structured design references they can call directly.

## Product Shape

The homepage is the tool: a prompt builder plus a live canvas for exploring visual systems. The library pages collect motion, components, interactions, styles, effects, and future templates. Each entry should be useful to both humans and agents: preview, prompt, negative prompt, tokens, and implementation notes.

Future exports may include MCP resources, JSON prompt packs, CLI search, or direct agent integrations.

## Open-Source Intent

UnBoring is open source so more designers and builders can contribute styles, motion patterns, templates, and design skills. Contributions should help AI-generated interfaces become more beautiful, diverse, practical, and human.

Do not copy proprietary code, assets, or visual identities from inspiration sites. Study design principles and translate them into original, reusable methods.

## Product Taste

UnBoring itself should feel opinionated, lively, and practical. It should avoid becoming another generic component gallery. The site should prioritize:

- Many distinct visual directions, not one house style everywhere.
- Useful prompts and anti-prompts, not vague adjectives.
- Real project contexts such as SaaS, games, education, healthcare, creative tools, portfolios, and data reports.
- Motion and interaction ideas that improve comprehension or delight.
- Static-site simplicity until a backend is genuinely needed.
